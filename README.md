# 🤖 Crypto Converter Bot

Premium Telegram bot for converting TON, USDT, INR, and Telegram Stars.

## 🚀 Features
- 💎 Live crypto prices from CoinGecko
- ⭐ Telegram Stars conversion (1 Star = ₹1.3)
- 🔐 Admin panel with premium emojis
- 📊 User tracking and statistics
- 📢 Broadcast messages
- 🚫 Ban/Unban system
- 📝 Customizable footer

## 🔧 Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Set environment variables in `.env`
3. Run: `python bot.py`

## 👑 Admin Commands
- `/admin` - Admin dashboard
- `/stats` - User statistics
- `/broadcast` - Send broadcast
- `/ban` - Ban user
- `/unban` - Unban user
- `/setrate` - Set Star rate
- `/setfooter` - Set footer
- `/logs` - View logs
- `/refresh` - Refresh prices
